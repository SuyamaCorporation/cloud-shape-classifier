# 雲の形分類ビジュアルガイド

積雲・層雲・巻雲・乱層雲など10種類の雲を、高度・形状・透明度・降水の4ステップで選択して判定できる雲分類アプリです。各雲種のSVGイラストと天気予報的意味を表示し、高度別分布図アニメーションや観察日記機能も備えています。

## 機能
- 4ステップ選択式の雲種判定ウィザード（高度/形状/透明度/降水）
- 10種類の雲（積雲/積乱雲/巻雲/巻積雲/巻層雲/高積雲/高層雲/乱層雲/層積雲/層雲）のSVGイラスト
- 各雲の国際名・略記号・高度帯・天気予報的意味・豆知識
- 雲ギャラリー：10種類を一覧表示
- 高度分布図：各雲種を正確な高度帯にプロットしたSVGダイアグラム
- 今日の雲 観察日記（日付・種類・メモをlocalStorageに保存）
